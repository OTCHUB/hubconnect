# Security Policy

## Scope

- On-chain program `hub` — `7c5oPs9GvX8vrC5jVFketNx1ZLuPs7HeH8Qc4XJx7b7i`
- TypeScript SDK and keeper in this repository

The program embeds [solana-security-txt](https://github.com/neodyme-labs/solana-security-txt);
`solana-verify` / explorers surface the same contacts as this file.

## Reporting a vulnerability

Report privately via
[GitHub Security Advisories](https://github.com/OTCHUB/hubconnect/security/advisories/new).
Do not open a public issue for security bugs.

Include the affected instruction/account, a reproduction (test or transaction on devnet), and
the impact you believe it has. We acknowledge reports within 72 hours.

## Disclosure

We coordinate a fix and a verified redeploy before public disclosure. Reporters are credited
unless they ask otherwise. No bounty programme is in place at this time.
